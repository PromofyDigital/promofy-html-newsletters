# Promofy HTML newsletters

Produce editable Brevo HTML that fits the campaign and works as an email. Use the current brief and latest supplied HTML first. The archive provides Promofy design and build examples.

## Pick the right reference

Open the [template library](references/template-library.md) and read only the example closest to the assignment. Use AI Suite for product announcements and blended hero artwork, Spark for trial offers, Halloween for a seasonal landing-page campaign, SBC for event bookings, and the anniversary email for an editorial layout.

Read the [production guide](references/production-guide.md) for a new build or substantial revision. For a targeted change, use the guide sections relevant to the edit. Keep the archived files as references and work on a campaign copy.

## Workflow

1. Establish the audience, primary action and destination, approved claims and assets, and the requested output. For a revision, preserve the approved source outside the requested changes. Flag missing offers, destinations, and assets rather than filling in campaign details from an old example.
2. Use one clear conversion path, a subject and complementary preview text, and live HTML for the message and buttons. Keep Brevo's native links literal. Preserve tracking and the matching destinations in standard and Outlook button markup. Use the approved palette in light and dark device settings and verify the mobile reading order. Reuse artwork from the archive only when the current brief calls for it.
3. Check desktop and narrow mobile previews, key content with images off, CTA destinations, and production placeholders. Keep a browser check distinct from an inbox check. Run Brevo previews or test sends when available and authorized, and report which checks remain. Live scheduling and sending require explicit authorization.
4. Deliver the editable Brevo HTML, a browser preview, and setup notes for a full build. Include new image assets and desktop/mobile screenshots where relevant. Match smaller edits to the requested scope. Label the HTML a draft if it still needs an image, destination, or approved fact.
